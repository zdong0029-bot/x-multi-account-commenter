连接已有 X 账号

你平时的 X 会话可直接复用，无需在新窗口重新登录。

首次加载扩展 · 只需一次
  1. 在已登录 X 的 Chrome 打开 chrome://extensions（Edge 用 edge://extensions）。
  2. 开启「开发者模式」→「加载已解压的扩展程序」，选择下方 extension 文件夹。
  3. 切回已登录的 X 标签页，点击本扩展图标，粘贴配对码，点「连接这个 X 标签页」。
  4. 保持扩展连接页打开，回这里点「检查连接」。

等待浏览器扩展连接

专用浏览器需要单独登录。如 X 提示登录受限，请使用扩展连接原本已登录的标签页。
