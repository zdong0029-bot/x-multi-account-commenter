# X 多账号评论助手 · v2

双击 Start.cmd 启动。本机面板默认地址为 http://127.0.0.1:18865 ，端口被占用时自动使用后面的空闲端口。

## 接入多个账号

账号列表不设固定数量上限，任务按本机资源排队执行。**每个同时运行的 X 账号使用独立的 Chrome / Edge 用户配置**；同一个用户配置的普通标签页共享登录状态，不能通过多开普通标签页隔离账号。

1. 在各自的浏览器用户配置中正常登录对应的 X 账号。
2. Chrome 打开 chrome://extensions（Edge 为 edge://extensions），开启开发者模式，加载本程序的 extension 文件夹。面板的“复制扩展文件夹路径”可复制准确位置。
3. 切回该账号的 X 标签页，打开扩展，填入面板配对码和账号备注，点击连接。保持扩展连接页存在。
4. 面板会出现该账号卡片。点“检查身份”，核对显示的 @账号。
5. 在其他独立浏览器用户配置中重复。连接新账号不会替换其他账号。

旧版升级时，在扩展管理页重新加载本扩展，再重新配对。本次扩展版本为 2.0.0。

## 为每个账号设独立规则

展开账号卡片的“这个账号的筛选和时间规则”：

- 博主标签组：每行一组，同义词用 | 分开，逗号也可分组。每个账号填写自己的领域。
- 匹配方式：默认全部标签组都命中，也可选择任意一组命中。
- 排除词：博主主页简介或公开分类命中排除词，就跳过。
- 找帖搜索词：仅用于发现候选帖子，留空时由标签生成；最终仍核对博主主页。
- 评论间隔：每轮完成后至少等待所填秒数再执行；每轮最多评论 1 条，没有匹配帖子就不评论。范围 30～86400 秒。
- 每日运行时段：采用北京时间，支持跨午夜；开始和结束相同表示全天运行。
- 每小时/每天上限：0 表示不额外限制条数；间隔和筛选仍生效。
- 评论语气：按这个账号的领域与表达方式生成中文评论。

填好后点“保存此账号规则”。修改前要先停止该账号，等待当前任务结束。

## 筛选准确性的边界与依据

执行顺序为：核对账号 → 找候选帖 → 检查蓝 V → 打开博主主页 → 读取简介/公开分类 → 匹配标签和排除词 → 生成针对原帖的评论 → 再核对主页与账号 → 发布。

蓝 V 按作者标记区的认证图标及颜色识别，金 V、灰 V、无标记和无法确认的标记不通过。X 改版可能需要适配。**帖子中提到某个关键词，不会被当作博主属于这个领域的证据。**

只使用主页简介和公开分类中的明确文字，不推断没有写出来的职业、兴趣或领域。拉丁字母按单词边界匹配，避免 AI 命中 daily；中文按完整词串匹配。同义词请显式写在同组中。

没有简介证据、标签不满足或身份不符时不发布。“最近的博主筛选依据”展示简介、通过/跳过理由。发布记录保存评论账号及匹配依据。同一篇帖子全局只由一个账号评论；已发出的相同评论文字不会再次自动发送。

## AI 与自动发布

在“共用 AI 设置”中填写支持 Chat Completions 的接口、模型和密钥。地址通常为 https://你的服务/v1，也支持完整的 /chat/completions 地址。

AI 接口共用，标签、语气和时间规则按账号独立保存。生成时，帖子、博主公开简介和这个账号的标签会发送给你指定的 AI 服务。密钥只在当前运行期间保存在内存，退出后需重填。

完成身份检查、保存标签、配置 AI 后，点该账号的“启动自动评论”。**启动表示授权它按已保存的规则自动生成并发布，不再逐条确认。** 新账号默认停止；没有标签或 AI 不能启动。

可独立停止任意账号，其他账号继续运行。已开始点击发送的操作会等待结果或进入待核对，停止不能撤回已发出的评论。

## 异常、重启与数据

- 发送结果不明：保留记录，该账号暂停，不自动重发。先到 X 核对，再处理发布记录。
- 登录身份变化、AI 或浏览器操作失败：该账号暂停并显示原因。
- 扩展离线：等待原账号连接，不用其他账号代发。
- 助手重启：账号任务先暂停，重新配对、填 AI 密钥并检查身份后再启动。
- 登录状态保留在原浏览器，不读取密码或导出 Cookie。规则、记录和公开筛选证据保存在 data/assistant.sqlite3。
- 点“退出助手”结束程序；只关面板不会结束后台。分享源码时不要附带 data 文件夹。

程序只做浏览、核对和评论，不执行点赞、关注、转发或私信。原来的手写和逐条确认流程仍可选用，左侧手动操作账号选择不影响其他自动任务。

## 验证范围

已使用本地模拟 X 页面与本地模拟 AI，验证两个独立浏览器连接、不同领域规则、自动评论、标签排除、非蓝 V 排除、逐账号身份与评论记录。真实 X 页面、实际账号和实际 AI 服务仍需用你的环境验证。

开发：Python 3.10+。旧版专用浏览器方式依赖 Playwright。可运行 python app.py --port 18865 --no-open；X_ASSISTANT_DATA 可指定数据目录。
